# Keyboard Shortcuts

Full reference of every keyboard shortcut in Smriti. The in-app
overlay (press <kbd>?</kbd> anywhere) shows a condensed version of
this list.

## Anywhere

| Key | Action |
|---|---|
| <kbd>?</kbd> | Toggle the keyboard-shortcuts overlay |
| <kbd>/</kbd> | Focus the search bar |
| <kbd>Esc</kbd> | Back · close overlay · cancel selection |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>,</kbd> | Open Settings |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>1</kbd> … <kbd>9</kbd> | Jump to sidebar section 1–9 |
| <kbd>Tab</kbd> · <kbd>Shift</kbd>+<kbd>Tab</kbd> | Move focus between cards / controls |

## Timeline (and any grid view)

| Key | Action |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> | Move highlight |
| <kbd>Enter</kbd> | Open the highlighted photo in the viewer |
| <kbd>Space</kbd> | Toggle selection on the highlighted photo |
| <kbd>Shift</kbd>+click | Range-select |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+click | Toggle a single photo's selection |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>A</kbd> | Select all photos currently in view |
| <kbd>PageUp</kbd> · <kbd>PageDown</kbd> | Scroll a viewport |
| <kbd>Home</kbd> · <kbd>End</kbd> | Jump to first / last |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Move selection to Trash |

## Photo viewer

| Key | Action |
|---|---|
| <kbd>←</kbd> · <kbd>→</kbd> | Previous · next photo |
| <kbd>Esc</kbd> | Back to gallery |
| <kbd>I</kbd> | Toggle the info panel |
| <kbd>+</kbd> · <kbd>−</kbd> | Zoom in · out |
| <kbd>0</kbd> | Fit to screen |
| <kbd>1</kbd> | Actual size (1:1 pixel) |
| <kbd>[</kbd> · <kbd>]</kbd> | Rotate left · right |
| <kbd>F</kbd> | Toggle fullscreen |
| <kbd>Space</kbd> | Toggle selection on this photo |

## Slideshow

| Key | Action |
|---|---|
| <kbd>Space</kbd> | Play · pause |
| <kbd>←</kbd> · <kbd>→</kbd> | Previous · next |
| <kbd>Esc</kbd> | Exit slideshow |
| <kbd>F</kbd> | Toggle fullscreen |

## People & Person Detail

| Key | Action |
|---|---|
| <kbd>Enter</kbd> | Open the highlighted person |
| <kbd>M</kbd> | Open the merge-person dialog (in Person Detail) |
| <kbd>R</kbd> | Open the rename dialog (in Person Detail) |

## Face review

When stepping through ambiguous face assignments:

| Key | Action |
|---|---|
| <kbd>Y</kbd> | Confirm — yes, this is the suggested person |
| <kbd>N</kbd> | Reject — no, queue for a different person |
| <kbd>Space</kbd> | Skip — decide later |
| <kbd>←</kbd> | Previous face |
| <kbd>→</kbd> | Next face |

## Map

| Key | Action |
|---|---|
| <kbd>+</kbd> · <kbd>−</kbd> | Zoom in · out |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> | Pan |
| <kbd>Esc</kbd> | Close pin popover |
