# Keyboard Shortcuts

Global:
- `?` open shortcuts overlay
- `Tab` / `Shift+Tab` navigate interactive cards
- `Cmd/Ctrl+,` open settings
- `Cmd/Ctrl+1..9` jump sidebar sections

Timeline:
- Arrows move highlight
- `Enter` open photo
- `Space` toggle selection
- `PageUp`/`PageDown`/`Home`/`End` scroll
