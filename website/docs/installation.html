Installation and Optional Assets

1) Install core app

  • Windows: MSI (recommended) or ZIP (portable).
  • Linux: Debian package or AppImage.
  • macOS: archive from release assets.

2) Optional one-click assets

On startup, PhotoVault prompts to install optional assets when missing. This prompt appears again on next launch until assets are installed.

Optional assets include:

  • ONNX Runtime library
  • Face models (`scrfd_10g_bnkps.onnx`, `glintr100.onnx`)
  • `geonames.db`

3) Manual fallback

If startup download fails, use release asset PhotoVault-Assets.zip and extract to your user data path under photovault/assets.
