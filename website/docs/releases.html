Release Process

  1. Run local verification scripts first.
  2. Push code when local checks are green.
  3. Create release tag v* to trigger packaging workflows.
  4. Verify smoke-test jobs and draft release assets.
  5. Publish release.

Expected release assets now include core installers plus PhotoVault-Assets.zip.
