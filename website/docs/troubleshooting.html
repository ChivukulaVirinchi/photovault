Troubleshooting

Asset prompt keeps appearing

PhotoVault repeats the prompt whenever optional assets are incomplete. Install assets and restart app.

People/face detection unavailable

Install optional asset pack from startup prompt or release asset PhotoVault-Assets.zip.

Geocoding unavailable

Ensure data/geonames.db exists in the optional asset install directory.

Windows SmartScreen warning

Expected for unsigned binaries. Use “More info” then “Run anyway”.
