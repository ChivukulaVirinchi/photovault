Getting Started

PhotoVault is an offline-first desktop app for organizing large photo libraries without cloud upload.

Typical first run

  1. Install the core app for your platform.
  2. Launch PhotoVault.
  3. If optional assets are missing, click Install Assets in the startup prompt.
  4. Select your photo drive/folder and start indexing.

Core vs optional assets

  • Core app: timeline, search, browsing, albums, cleanup workflow.
  • Optional asset pack: face recognition models + ONNX runtime + GeoNames database.
