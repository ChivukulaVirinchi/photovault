Architecture Overview

  • UI: Rust + iced state machine.
  • Storage: SQLite via rusqlite.
  • ML: ONNX Runtime with optional asset pack.
  • Search/Cleanup: local indexing, duplicates, bursts, culling workflow.

The app is designed to stay useful even when optional ML/geodata assets are not installed.
